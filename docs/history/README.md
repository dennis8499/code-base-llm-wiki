# Historical inputs

This directory records design provenance without treating historical material as
the current product contract.

- `llm-wiki.md` attributes and summarizes the upstream LLM Wiki concept while
  linking to its authoritative source.
- `original-prompt.txt` preserves the project owner's initial local request.

Current behavior is defined by `AGENTS.md`, the `$codebase-wiki` skill,
`capabilities.json`, tests, and the maintained product documentation.
